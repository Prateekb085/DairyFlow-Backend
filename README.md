# DairyFlow Backend

A Spring Boot backend for a Milk Collection and Payment Management System.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- MySQL
- Maven

## Features

- User Registration
- User Login
- JWT Authentication
- Farmer Management

## Upcoming Features

- Milk Collection
- Payment Module
- Dashboard
- Reports
- Notifications
- React Frontend
